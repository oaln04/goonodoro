# 🍅 Project Goonodoro

A no-nonsense Pomodoro timer built for the gooniverse. Stay locked in, take your breaks, repeat.

## Features

- 25-minute countdown timer
- Start, Pause, and Reset controls
- Auto-stops and switches mode when the session ends
- Dynamic status messages to keep you accountable

## How to Run

No installs. No dependencies. Just open `index.html` in your browser and get to work.

## Built With

- HTML
- CSS
- Vanilla JavaScript
